## DC02 还是 DC03：洛杉矶两个机房的实际差别

洛杉矶是 RackNerd 对国内用户最有价值的机房位置，西海岸物理距离近，延迟天然比纽约、芝加哥低几十毫秒。这里有两个机房，线路和用途完全不同。

**DC02（Multacom）** 是国内访问表现更好的那个。按第三方测评给出的路由：去程电信走 163 直连、联通走 169 直连、移动走香港 CMI，回程三网 BGP 直连。同一份测评提到国内平均延迟约 197ms，上海电信最快能到 135ms 左右；联通和移动丢包较少，电信在晚高峰可能出现轻微抖动。

**DC03（ColoCrossing）** 线路稍逊，换来两个实用特性：美国原生 IP，以及开放 25 端口。发邮件、注册某些对 IP 归属敏感的服务，DC03 更合适。

选择规则一句话：**国内访问、代理中转、远程开发优先 DC02；要原生 IP 或邮件功能选 DC03。**

有一点要提醒：新上架的特价套餐，可选机房列表未必包含 DC02。有渠道整理的最新特价信息里，洛杉矶只列了 DC03，其余是纽约、西雅图、圣何塞、芝加哥、达拉斯。下单页的机房下拉框是唯一准确的信息源，如果 DC02 不在列表里，DC03 仍然能用，只是国内访问体验会差一档。

## 买之前必须知道的几个限制

**没有 CN2 GIA 专线。** 官方在售的是普通 BGP 线路，晚高峰电信方向偶尔波动。对延迟极其敏感、要求稳定 150ms 以内的场景，需要自己配加速工具或者换定位更高的产品线。

**换 IP 只有 72 小时免费窗口。** 购买后 72 小时内可以在控制面板自助换一次 IP，不收费；超过 72 小时，每次换 IP 收 $3。建议开通后立刻测 IP 的可用性，有问题当天处理，别拖到第四天。这一条在很多推荐文里不会提，但它是买完之后最容易产生额外支出的地方。

**无管理型服务。** 系统安全、软件更新、数据备份都得自己来。RackNerd 提供 24/7 支持，处理的是平台层面的问题（网络、硬件、开通），不包括帮你调 Nginx 配置。没有 Linux 基础的话，前期学习成本要算进去。

**控制面板授权另算钱。** 想要 cPanel 这类商业面板，授权费可能比 VPS 本身还贵。个人站用 CyberPanel、CloudPanel、宝塔这类免费方案更划算，官方 ctrl 里也提供了一键安装。

**限量款会缺货。** $10.60 和 $18.66 两档属于社区特价，售完即止，不补货。看到缺货不用反复刷新，直接选 $21.99 的常规款。

**能装什么系统。** 官方列出的一键重装列表是 CentOS、Rocky Linux、AlmaLinux、Fedora、Debian、Ubuntu，自定义 ISO 需要开工单申请。想装 Windows 的话，授权和可行性要单独问客服确认，别默认包含。
